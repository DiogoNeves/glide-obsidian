# Daily Glide Check-In

## Installable Prompt

Run `$glide-daily-check-in` for this vault. Read `Agent HQ/AGENTS.md` and its selected canonical checklist. Recorded memory cutover selects job `daily`; otherwise follow the preserved legacy workflow. Retain the installed source scope, pending work, knowledge-review requirements and external-action authority. Return only the procedure's useful output and actual receipts; unchanged work stays quiet. Do not change schedules, models, permissions or writers through this invocation.

## Suggested Schedule

- Cadence: daily or weekdays
- Time: user-preferred morning time
- Workspace: the Obsidian vault where Glide is installed
- Output: short message in the harness thread or configured automation destination

## Install Notes

- Confirm before enabling.
- Record the active schedule in `Agent HQ/Automation Registry.md`.
- If the harness cannot schedule recurring runs, keep this as a proposed manual automation.
