# Nightly Research Review

Without recorded versioned-memory cutover, follow `Reference/Legacy Workflows/Nightly Research Review.md` only. With cutover, run `glide-dream` using `Checklists/Dream.md`. Preserve the existing cadence, source scope and authorization; this route does not install or enable a scheduler.

Research only when it could materially improve a current decision or future advice. Use `glide-deep-research-subject` for source-heavy questions. Quiet unchanged runs need no user-facing report; surface material blockers, needed judgment or discoveries that should not wait.
