# Area Review

Review one area for a useful next decision. Without recorded memory cutover, use `Reference/Legacy Workflows/Area Review.md` only.

With cutover, retrieve current goals, constraints, open operations and relevant guidance through `Memory Protocol.md`. Read the target area's AGENTS rules and only linked area/project sources that affect the question; legacy Context/Goals/Reminders/Questions/Decisions are historical or explicitly unmigrated evidence.

Summarize current state, active goals, neglected responsibilities, due/stale reminders, missing information, contradictions, overload and cross-area effects. Broaden retrieval when another area's constraint might invalidate the recommendation. Use independent parallel tracks when useful, then integrate conflicts and remove duplication.

Recommend next actions or experiments, with the evidence and one material question if needed. Save useful questions, reminders, decisions and tensions as sourced managed records against current revisions. Do not maintain migrated state in legacy queues/registers. Bring required input into conversation and preserve unresolved evidence.
